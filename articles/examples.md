# Examples and galleries

All examples of rvis in one place: the examples of every chart type,
drawn by every plotter, in the chart guides; and the example dashboards
that come with the package.

## Chart examples

Each chart guide shows its chart types on one R data set, with an
example for each plotter drawing that type. The examples need the
plotting package of their plotter; with the package installed, you can
copy and run them as they are.

## Example dashboards

rvis comes with 40 example dashboards (YAML files in folder `dashboards`
of the package). List them with
[`rvisDashboardExample()`](https://genpack.github.io/rvis/reference/rvisDashboardExample.md),
and run one with `runDashboard(rvisDashboardExample("<name>"))`:

``` r

rvisDashboardExample()                              # name, group, title and file of each example
runDashboard(rvisDashboardExample("faithful"))      # runs one
file.edit(rvisDashboardExample("faithful"))         # opens its configuration, to copy and change it
```

They are in three groups:

- **[Gallery](https://genpack.github.io/rvis/articles/dashboard-gallery.md)**:
  20 apps of the [Shiny gallery](https://shiny.posit.co/r/gallery/)
  rebuilt from YAML, with a screenshot of each.
- **[Showcase](https://genpack.github.io/rvis/articles/dashboard-gallery.html#showcase-dashboards)**:
  two large dashboards combining most features.
- **Basics**: small dashboards showing one feature each, explained in
  the dashboard guides.
