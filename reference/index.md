# Package index

## Charts

Draw a chart with any plotter, and send clicks on its items to shiny.

- [`rvisPlot()`](https://genpack.github.io/rvis/reference/rvisPlot.md) :
  Plot with an rvis wrapper
- [`rvisClickEvents()`](https://genpack.github.io/rvis/reference/rvisClickEvents.md)
  : Send clicks on a chart to shiny
- [`df2Network()`](https://genpack.github.io/rvis/reference/df2Network.md)
  : Build a network from the levels of a table
- [`plotHtml()`](https://genpack.github.io/rvis/reference/plotHtml.md) :
  Show a chart in the web browser

## Dashboards

Build and run shiny dashboards from YAML, JSON or R list configurations.

- [`rvisDashboard()`](https://genpack.github.io/rvis/reference/rvisDashboard.md)
  : Build a dashboard from a configuration
- [`runDashboard()`](https://genpack.github.io/rvis/reference/runDashboard.md)
  : Run a dashboard
- [`rvisDashboardExample()`](https://genpack.github.io/rvis/reference/rvisDashboardExample.md)
  : Example dashboards
- [`DASHBOARD-class`](https://genpack.github.io/rvis/reference/DASHBOARD-class.md)
  [`DASHBOARD`](https://genpack.github.io/rvis/reference/DASHBOARD-class.md)
  : Dashboard objects
- [`build.container.get.table()`](https://genpack.github.io/rvis/reference/build.container.get.table.md)
  : Dashboard items of a dialog reading a CSV table
- [`style.css()`](https://genpack.github.io/rvis/reference/style.css.md)
  : Inline CSS style
